# Zomato Bangalore Analysis - Power BI Dashboard

## 📊 Project Overview
Analyzed 9,249 restaurants across Bangalore to identify market trends, high-demand locations, and pricing strategies.

## 📸 Dashboard Preview


*Dashboard analyzing location distribution, online order availability (100%), and cost vs rating correlation.*

## 🔍 Key Insights
- **Top Locations:** BTM, Koramangala, Bannerghatta Road have highest restaurant density
- **Online Ordering:** 100% of restaurants on Bannerghatta Road offer online delivery
- **Pricing:** Analyzed cost vs average rating to find sweet spot for new restaurant

## 🛠️ Tools Used
- Power BI Desktop
- Power Query for data cleaning
- DAX Measures

## 📁 Files in this Repository
- `Zomato_Bangalore_Cleaned.csv` - Cleaned dataset
- `Dashboard Screenshots` - Power BI visuals

## 📌 Business Problem Solved
Helps entrepreneurs decide WHERE to open a new restaurant and WHAT price range works best in Bangalore.
