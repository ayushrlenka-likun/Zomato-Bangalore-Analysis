# Zomato Bangalore Analysis - Power BI Dashboard

## 📊 Project Overview
Analyzed **9,249 restaurants across Bangalore** to identify market trends, high-demand locations, and pricing strategies. This dashboard helps to understand where to open a new restaurant and what price point works best.

## 📸 Dashboard Preview

**Filtered View - Bannerghatta Road:** Shows 214 restaurants, 100% online order availability, and cost vs average rating analysis.

## 🔍 Key Insights
- **Top Locations:** BTM, Koramangala, and Bannerghatta Road have highest restaurant density
- **Online Ordering:** 100% restaurants in filtered view offer online delivery - huge market
- **Pricing Strategy:** Cost for Two vs Rating correlation shows best pricing between ₹400-₹600
- **Interactive Filters:** Location and Online Order slicers for deep-dive analysis

## 🛠️ Tools Used
- Power BI Desktop
- Power Query (Data Cleaning)
- DAX
